# 魔法留声 · 霍格沃茨开放世界初版

**[在线打开魔法留声](https://ywacle.github.io/game-design/)** · [直接进入开放地图](https://ywacle.github.io/game-design/world/)

在首页可以写回忆、从「走进霍格沃茨」直接进入八个室内场景，或从「探索霍格沃茨地图」开始步行。回忆保存在当前浏览器和站点域名下。迁移旧站回忆时，在旧站「备份回忆」，再在 GitHub Pages 首页「导入回忆」。

八处可漫游的霍格沃茨场景，与私人回忆录连接成一个网站。室内场景包括烛光礼堂、决斗场、魔药课教室、占卜课教室，以及格兰芬多、斯莱特林、拉文克劳、赫奇帕奇休息室。

首页「探索霍格沃茨地图」进入同一个连续室外场景。15 个地点涵盖黑湖、城堡、西谷球场、温室、禁林与霍格莫德。选择地点后可步行，走近室内入口可进入八个旧场景，使用「返回室外地图」回到原入口。键鼠使用 WASD 或方向键移动，拖动转向，M 回到全图。触屏使用方向按钮。

室外模型保存在 `world/model/Hogwarts_Grounds.blend`，内含可编辑建筑及已打包纹理。色彩与比例处理在 Blender 中完成。网页读取导出的 GLB。室外总图见 `world/ground-plan.png`，网页截图与参考对照位于 `world/preview.png` 和 `world/reference-comparison.jpg`，美术许可见 `world/CREDITS.md`。早期 Linux 回忆录单独保存在 `memoir-linux/`。

「沿新生路线入校」从月下栈桥出发，经过船屋、上山石阶与钟庭抵达礼堂。浮标显示室外下一段的方向与距离。进门后沿长桌走过烛光，在席位旁点「写下入校这一天」。打开「地点目录」可选择其他路线。四个学院的入口有画像、门环、木桶和暗门，各有一段可点选的回应。返回室外时面向来路。

从黑湖到西谷球场共用同一片暮色天空。网页新旧实景与参考对照见 [入校与校园对照图](world/arrival-comparison.jpg)。用 `/world/?view=honeydukes` 查看原创蜂蜜公爵橱窗，或用 `/world/?view=house-doors` 查看北廊的两扇学院门。

在地图网址后加上 `?view=water` 可直接到黑湖泊位。船屋、小船和铁灯随视角投下倒影，浅水处可见湖底碎石。同机位的新旧网页截图见 `world/lake-comparison.jpg`。

沿西线可穿过山谷廊桥，桥内机位为 `/world/?view=gallery`。黑湖和廊桥的官方插画、上一版及本版浏览器原色截图见 `world/style-comparison.jpg`。

球场可从西线穿过山谷廊桥步行抵达。草地机位为 `/world/?view=pitch`，官方季赛画面与新旧网页实景对照见 `world/pitch-comparison.jpg`。

## 全地图

15 处地标组成同一个可步行的室外世界，开放 8 个室内场景。地点目录中有六条导览。新生入校线从黑湖到礼堂，西线经廊桥到魁地奇球场，东线经温室和海格小屋到禁林，北线穿过霍格莫德到车站。北部环线可从禁林经车站和村庄走回城堡，城堡环线经过地下教室和学院塔楼入口。

室外尺度、建筑间距和路线按连续步行设计。温室、海格小屋、村庄与站屋以室外游览为主。蒸汽机车在月台边静态展示。画风参考《魔法觉醒》场景，城堡、山谷和各地标关系借用电影与片场设定。网页实景、出处与区别见 `world/campus-comparison.jpg` 和 `world/CREDITS.md`。

`world/ground-plan.png` 与网页路线共用 `layout.json` 和 `navigation.json`。编辑布局后可用 `python world/model/draw_plan.py` 重新绘图。该命令依赖 Pillow 和 Noto Serif CJK，也可以通过 `HOGWARTS_PLAN_FONT` 指定可用的中文字库。

## 在本地打开

从 GitHub 克隆后，在仓库目录运行 `npm ci`、`npm run build` 和 `npm start`。GitHub Actions 在 `main` 更新时自动测试并发布到 GitHub Pages。

完整解压后，Windows 双击 `Start-Windows.cmd`。安装了 Node.js 20+ 的电脑也可在本文件夹执行 `node server.mjs --open`；Python 3 用户可执行 `python server.py --open`。macOS 可在终端执行 `sh Start-Mac.command`，该启动器未在实体 Mac 验证。

默认地址是 `http://127.0.0.1:4175/`。保持启动窗口运行。`dist/` 已包含网页、图片、GLB、Three.js 和本地 Draco，使用时不需要安装 npm 依赖或联网。请通过启动器的本地 HTTP 服务打开，直接双击 HTML 无法正确加载 ES Modules 和模型。

端口 4175 被其他程序占用时，先关闭对应的旧版本启动窗口，再启动本版。也可设置环境变量 `MEMORIES_PORT` 使用其他端口；改变端口会改变浏览器存储位置，需要用回忆备份导入迁移。

## 一次旧地重游

1. 首页点击「走进霍格沃茨」，选择八处场景中的任意一处。
2. 六处教室与休息室支持拖动旋转、滚轮缩放、三个观景点和地面漫游。礼堂及决斗场保留原有控制。
3. 点击「开始漫游」后，WASD 或方向键行走，Shift 加快，鼠标转头；Esc 退出。鼠标锁定不可用时，按住画面拖动环顾。触屏进入漫游后显示方向键。
4. 上方「前往」可切换全部八个地点，「回忆录」回到首页，「写下此刻」带上当前地点和封面。
5. 保存故事后，可以从故事详情「重返」对应场景。H 隐藏或恢复界面，R 回到主视角，右上角问号查看操作。六处教室与休息室的「微光」可以开关。

占卜教室的漫游路线位于中央地面通道；两侧高台作为陈设区不可直接登上。

首页「相册里的旧时光」中的廊桥、天文塔、宿舍保留原版插画回望，不代表额外可漫游场景。

## 保存回忆

室外漫游时，地点卡片上的「写下此刻」会把当前位置和视角带进回忆表单。保存后，故事详情的「重返」可以回到记录的位置。地图地点卡片上的「此地回忆」可打开该地点的故事列表，导入或导出 JSON 回忆时也会保留这些位置。

在室内观景时写下的回忆会保留观景点。行走时，记录最接近的预设机位。新生路线的专用入口会保存长桌旁的机位。旧故事仍可重返原房间，备份也会保存新故事的机位。

沿用 `hogwarts-always-v1` 本地存储键与版本，旧故事、收藏、学院、JSON 备份仍兼容。新增六个地点和对应回忆封面。故事不上传；换浏览器、端口或清除网站数据会影响回忆可见性。

旧网页的数据若不在相同浏览器、域名和端口，请先在旧版点击「备份回忆」，在本版点击「导入回忆」选择 JSON。导入合并已有故事，重复导入不重复添加，相同编号的不同故事另存。保存失败会提示并保留草稿。建议定期备份。

## 交付内容

- `dist/` 由 `npm run build` 生成，包含可离线运行的网页和模型。
- `src/memoir/`：回忆录与八场景入口。
- `src/interior/`：六处教室与休息室共用的查看器、控制与家具碰撞。
- `src/hall/`、`src/arena/`：本轮修订后的礼堂与决斗场查看器。
- `src/shared/`：地点目录、统一导航、回忆存储与合并逻辑。
- `scene-assets/`：全部八场景 GLB 和机位/边界数据。
- `model/`：八场景可编辑 `.blend`、重跑脚本和作者纹理。礼堂以 `Great_Hall_ArtRefined.blend` 为本轮源文件，保留重建所需的前序基础。每处新场景有制作说明。
- `previews/`：实际网页截图、各观景点、窄屏截图与单独标识的 Blender 渲染。
- `Visual_Review.md`：逐场景修改效果及仍可见的美术差异。
- `GITHUB_RESEARCH.md`：实际查阅的 GitHub 代码、提交、许可证和本次采用的技术。
- `references/`、`REFERENCES.md`：原色官方参考、来源与创作边界。
- `Official_Comparison.jpg`、`comparisons/`：八场景官方图 / 修改前网页 / 本轮网页三列比较。
- `VERIFICATION.md`、`verification.json`：浏览器操作、资源与交付验证，以及准确的未测范围。
- `tests/`：旧数据兼容、新地点备份往返、家具/边界碰撞与输入逻辑检查。

## 编辑和重建

网页使用固定的 Three.js 0.180.0 和 esbuild 0.25.11。执行 `npm ci`、`npm test`、`npm run build`。普通浏览无需运行这些命令。模型使用 Blender 5.3；打开相应 `.blend` 即可编辑。建模、烘焙和导出步骤见各 `model/<场景>/` 说明与脚本，GPU 不可用时需按机器调整渲染设备。源材质纹理已打包或存于相邻文件夹。

此项目是原创建模习作，重点是参考画面的空间轮廓、色块、主道具与光色。隐藏区域、尺寸和背墙为原创补全；人物、精细雕刻、逐像素手绘笔触与游戏原作仍有差距。未加入角色、战斗、多人或云端同步。来源和权利说明见 `REFERENCES.md`。
